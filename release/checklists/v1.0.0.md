# Omybuntu v1.0.0 release checklist

Status: pending

Record the tester, hardware, date, and evidence link or notes for every item.
Change the status to `approved` only after every item passes and all blocking
issues are closed or fixed in the release commit.

## Automated gates

- [ ] CLI test passes in GitLab CI
- [ ] ISO integrity test passes in GitLab CI
- [ ] Update discovery regression test passes in GitLab CI
- [ ] Versioned ISO builds successfully from the RC commit
- [ ] SHA-256 verification passes after downloading the published artifact
- [ ] GPG signature and published fingerprint verification pass
- [ ] ISO metadata reports `v1.0.0` and channel `stable`

## Boot and installation

- [ ] Live session boots in UEFI mode
- [ ] Clean full-disk installation completes
- [ ] Encrypted full-disk installation completes and unlocks after reboot
- [ ] Secure Boot installation boots successfully
- [ ] Windows dual-boot installation preserves Windows and boots both systems

## Hardware matrix

- [ ] Intel or AMD integrated graphics session works
- [ ] NVIDIA graphics session works
- [ ] Wi-Fi connects and remains stable
- [ ] Bluetooth pairs and reconnects
- [ ] Speaker, headphone, and microphone audio work
- [ ] Suspend and resume work without session or network loss
- [ ] External monitor is detected and usable

## Upgrade and channels

- [ ] Installed RC updates to the final release commit without data loss
- [ ] `dev`, `rc`, `stable`, and `edge` channel changes select the correct branch
- [ ] Stable update discovery ignores dev and RC tags
- [ ] No unresolved blocker affects data safety, boot, installation, network,
      graphics, or updating
